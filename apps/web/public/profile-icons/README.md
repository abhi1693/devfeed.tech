# Profile brand icons

Generated from Simple Icons 16.33.0 (CC0-1.0), preserving the paths previously
bundled in ProfileLinkIcon. Only selected brands are requested, as same-origin
mask images; no profile URL is contacted. Chrome and Edge packages include these
assets locally. SVG filenames contain a SHA-256 content hash so long-lived
caching is safe. When changing an icon, regenerate its hash and update the map
in ProfileLinkIcon; do not overwrite an existing hashed asset with different bytes.
